## My process

### Built with

- Semantic HTML5 markup
- SCSS (partials, mixins, design tokens)
- CSS custom properties
- Flexbox
- Mobile-first workflow
- Vanila JavaScript for dropdown logic
- Accessible ARIA attributes for navigation

### What I learned
 
 In this project I've learned how to make an accessible dropdown navigation, using aria-expanded and aria-controls.
 I focused on a clean, scalabel SCSS architecture using design tokens, mixin, partials and BEM naming.
 I'M usinf Flexbox to create a responsive layout.
 I'm using Vanila JavaScript for the dropdown logic.
